⑤ 鉴权与安全规则
谁可以访问（认证） + 能访问什么（授权） + 内容怎么防护（脱敏 / 过滤 / 黑白名单）
安全能力边界
网关做「身份 + 授权 + 内容」三层；网络层攻击交给前置 WAF / 云防火墙，避免重复建设
网关自建
认证：JWT / AK-SK / OAuth2 / mTLS
授权：API 订阅授权、scope 校验
访问控制：IP 黑白名单、AppCode 黑白名单
内容：敏感数据脱敏、请求体字段过滤、响应裁剪
限流：与限流熔断页同一套规则引擎
网关协同
SSL/TLS 卸载：网关终止证书，内网 HTTP 回源
入侵检测：拦截结果透传 X-WAF-Risk 头，网关按风险等级处置
防爬虫：与风控系统联动，网关执行处置动作
审计：请求响应留痕，对接 SIEM
不建议网关做
DDoS 清洗、防病毒 / 木马查杀 → 交给云防火墙、安全网关
深度包检测（DPI）→ 交给专业安全设备
大文件病毒扫描 → 交给对象存储的内容安全服务
理由：网关是 Java 响应式链路，做重安全检测会拖垮吞吐与延迟
