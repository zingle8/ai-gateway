查询表达式
与界面条件等价，便于复用与分享（真实实现可对接 ES / ClickHouse / Prometheus）
-- 数据源：gateway_access_log（明细 7 天 / 小时聚合 90 天 / 天聚合 2 年） SELECT time_bucket(5m, ts) AS 时间, route_id, count(*) AS 请求数, count_if(status >= 500) AS 错误数, round(count_if(status >= 500) * 100.0 / count(*), 2) AS 错误率, quantile(0.99, latency_ms) AS p99 FROM gateway_access_log WHERE ts BETWEEN '2026-10-29 17:00' AND '2026-10-30 17:00' AND upstream = 'search-service' AND route_id LIKE '%search-api%' AND status >= 500 AND latency_ms >= 300 GROUP BY 时间, route_id HAVING 请求数 > 100 ORDER BY 错误率 DESC LIMIT 1000;

使用说明
数据粒度与保留
访问明细（含 TraceId）保留 7 天；5 分钟 / 小时聚合保留 90 天；天聚合保留 2 年。超过保留期的条件请改用天粒度查询。
导出限制
单次导出上限 10 万行，超出请在条件中缩小时间范围或改用天粒度；导出任务异步执行，完成后站内下载。
和另外两个页面的分工
网关总览看「现在是否健康」；数据统计查询（本页）做「自定义取数、下钻、导出」；链路追踪与日志查「单条请求的根因」。
