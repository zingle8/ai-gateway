接入方式：手动 还是 自动？
本页是手动填写；若应用能自己在启动时声明身份，用自动接入更快、且不容易配错
对比项手动接入（本页）自动接入 · 配置即接入
谁来填人在控制台填全部字段应用启动读 bootstrap.yml / gateway.yaml 自动注册
需要填多少项目 ID / 名称 / 地域 / 等级 / 语言-服务名 / 类型 / Nacos 空间等 10+ 项最少 4 项：appcode、服务名、地域、等级
基础配置需逐项手动设置按等级下发默认模板（QPS / 超时 / 重试 / 熔断 / 鉴权）
耗时15 ~ 30 分钟约 12 秒（随应用启动完成）
适用范围兜底、临时接入、无法改造的存量系统Spring Boot（Starter）、多语言（YAML）、K8s（注解）全覆盖
两者关系最终落到同一份系统模型：手动接入 = 人替系统调用注册接口；控制台改过的字段会被锁定，自动接入不会覆盖
