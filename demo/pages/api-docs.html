接口文档
网关统一 Base URL：https://gw.example.com · 后端微服务地址不对外暴露
公共请求头
所有接口统一由网关 AuthFilter 校验，业务服务无需重复实现鉴权
X-App-Code应用标识，用于限流 / 计量 / 审计
X-SignatureAK-SK 签名结果（HmacSHA256）
X-Timestamp秒级时间戳，5 分钟内有效
X-Nonce随机串，防重放
AuthorizationJWT 模式：Bearer <token>
X-Tenant-Id租户标识（多租户隔离）
X-Trace-Id可选，未传由网关生成并透传
Content-Typeapplication/json;charset=UTF-8
创建订单
POST /api/order/create
需幂等键
# 请求 curl -X POST https://gw.example.com/api/order/create \ -H "X-App-Code: crm-app" \ -H "X-Signature: <sign>" \ -H "X-Timestamp: 1761780000" \ -H "Content-Type: application/json" \ -d '{ "userId": "U10086", "items": [{"skuId": "SKU-1", "qty": 2}], "idempotentKey": "8f2a91c7" }' # 响应 { "code": 0, "message": "success", "data": { "orderId": "SO20261030001", "amount": 199.00, "status": "CREATED" }, "traceId": "6f2c1a9b8e7d4c3f" }
Java 调用示例（OpenFeign）
内部服务通过 Feign 走网关，统一鉴权与灰度
// 1) 声明式客户端 @FeignClient(name = "api-gateway", url = "https://gw.example.com") public interface OrderClient { @PostMapping("/api/order/create") OrderResult create(@RequestHeader("X-App-Code") String appCode, @RequestHeader("X-Signature") String sign, @RequestBody OrderCmd cmd); } // 2) 统一加签拦截器 @Bean RequestInterceptor signInterceptor(Signer signer) { return template -> { String ts = String.valueOf(System.currentTimeMillis() / 1000); template.header("X-App-Code", appCode); template.header("X-Timestamp", ts); template.header("X-Nonce", UUID.randomUUID().toString()); template.header("X-Signature", signer.sign(template, ts)); }; }
