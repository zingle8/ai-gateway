协议支持与转换 · 负载均衡 · 流量分发
同一套路由模型承载 HTTP / gRPC / WebSocket，网关负责协议适配与转发
HTTP · HTTP/2 · gRPC · WebSocket
① 协议转换（HTTP ↔ gRPC）
# 外部 REST → 内部 gRPC，JSON 自动映射 Proto POST /api/pay/create ↓ JsonToGrpcFilter（proto 描述符解析） PayService/Create (HTTP/2) ↓ GrpcToJsonFilter {"code":0, "data":{...}}
无需业务改造：Proto 文件上传至控制台即生成转换规则与字段映射。
② WebSocket 转发
# ws 握手鉴权 → 长连接透传 → 计量 ws://gw/ws/notify?appcode=xxx ↓ WsAuthFilter（握手期校验 JWT/AK-SK） ↓ 与后端保持长连接，双向帧透传 ↓ 按连接数 + 消息数双维度计量
支持连接数限流、空闲超时、单连接消息速率限制。
③ 服务编排（聚合多后端）
# 一次请求并行调用 3 个服务并聚合 GET /api/order/detail/{id} ├─ order-service (必需) ├─ user-service (必需) └─ pay-service (可降级) ↓ 并行 + 超时兜底 → 聚合响应
必需依赖失败整体失败，可降级依赖返回默认值，避免串联放大延迟。
