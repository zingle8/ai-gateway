API 发布流程
API 是「契约」，先定契约再配路由，避免路由先上线、文档后补
① 定义 API
方法 / 路径 / 版本 / 分组
支持 OpenAPI 3.0 导入
② Schema 校验
入参 / 出参 JSON Schema
网关按 Schema 自动校验
③ 评审
兼容性检查 + 负责人审批
破坏性变更自动拦截
④ 灰度发布
按 appcode / 地域放量
观察错误率与 RT
⑤ 全量上线
文档同步生成
旧版本保留 90 天

// v2 → v3 diff（创建订单） + "idempotentKey": string // 新增必填（破坏性！） + "items[].skuId": string // 兼容 - "items[].productId" // 删除字段（破坏性！） ~ "amount": int → decimal // 类型变更（破坏性！）
发布策略
兼容变更（新增可选字段）可直接全量
破坏性变更必须新版本 v3 + 双版本并行 90 天
旧版本下线提前 30 天通知全部订阅方
Schema 校验网关按 Schema 拦截非法入参
